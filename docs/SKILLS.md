UI UX Pro Max содержит свои Python-скрипты и CSV. Проверенный пример:

```sh
python3 .agents/skills/ui-ux-pro-max/scripts/search.py "keyboard focus" --domain ux -n 1
```

Его команды в `SKILL.md` адаптированы к относительному пути `.agents/skills/ui-ux-pro-max/scripts/search.py`. Данные и алгоритмы не изменялись.

Impeccable содержит launchers для Windows и POSIX, контрольные суммы и ссылки. Бинарный движок, кэши, hooks и локальная конфигурация предыдущего компьютера не переносились. При первом запуске launcher может скачать соответствующий движок; действовать по разрешениям текущей среды. Если запуск недоступен, читать reference-файлы и выполнять работу доступными инструментами. Пользователь поручил начинать и доверил обычные решения; рекомендации навыка не должны превращаться в повторные формальные согласования известных требований.

Web Design Guidelines загружает актуальные правила из отдельного публичного файла Vercel при применении. Версия правил может отличаться от даты фиксации самого навыка.

## Что показал отбор

Визуально просмотрено авторское сравнение Villa Castagneto из Impeccable: вариант после демонстрирует гораздо более цельную сцену и характер. Также просмотрены два примера Taste Skill: кофейня и страница событий. Taste не включён из-за жёстких предписаний структуры текущей версии. Скриншот UI UX Pro Max аккуратен, но сам по себе не доказывает необычность; этот навык выбран прежде всего как справочник. Отдельного независимого сравнительного теста эффективности не проводилось; навыки не гарантируют итоговое качество без визуальной проверки.
