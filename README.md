# GOODSPORTS — пакет для редизайна

Чистая передача проекта другому рабочему аккаунту GPT. **Готового нового дизайна здесь ещё нет:** следующий агент должен разработать и реализовать его самостоятельно.

**Начать:** прочитать [PROMPT.md](PROMPT.md), [AGENTS.md](AGENTS.md) и [docs/BRIEF.md](docs/BRIEF.md).

Исходный сайт: https://team.goodsports.ru/. Снимок материалов: 16 ноября 2026 года. Репозиторий приватный.

## Что внутри

| Путь | Для чего |
| --- | --- |
| `PROMPT.md` | Полный стартовый промпт для нового GPT |
| `docs/BRIEF.md` | Требования пользователя и факты о продукте |
| `docs/HANDOFF.md` | Точный статус, ограничения и что делать дальше |
| `docs/SKILLS.md` | Выбранные навыки, версии и переносимость |
| `docs/ASSETS_MANIFEST.json` | Источники и SHA-256 материалов снимка |
| `reference-site/` | Автономный снимок действующего фронтенда и его ресурсов |
| `reference-site/img/hero-desktop.webp` | Текущий баннер для компьютера |
| `reference-site/img/hero-mobile.webp` | Текущий баннер для телефона |
| `data/catalog.json` | 37 категорий с исходными ценами, картинками и ссылками |
| `data/content.json` | 10 ответов FAQ, 5 отзывов и 5 фотографий команд |
| `.agents/skills/` | Четыре выбранных дизайн-навыка со своими ресурсами |
| `tools/verify_handoff.py` | Проверка целостности и состава передачи |

## Просмотр исходного сайта локально

Из корня репозитория:

```sh
python3 -m http.server 4173
```

Открыть `http://localhost:4173/reference-site/`. На Windows можно использовать `python` вместо `python3`.

Это **снимок для изучения**, а не готовый редизайн. Счётчики аналитики и CRM-виджет из HTML исключены. В снимке отправка формы заблокирована, чтобы тестовые заявки не ушли на действующий сайт. Исходный публичный JS сохранён; серверный обработчик формы и его конфигурация отсутствуют.

## Что намеренно не включено

Исходная папка создавалась для изготовления баннера. В репозиторий не копировались её концепты, коллажи, промежуточные генерации, слои, блок-ауты, старые версии, локальный `my4.html` с устаревшими ценами, `node_modules`, незавершённый React-черновик, экспериментальная 3D-модель, локальные настройки хостинга, кэши и история чата. Текущий баннер взят непосредственно с работающего сайта.

## Доступ с другого аккаунта

Новый рабочий аккаунт GPT должен иметь доступ к этому приватному репозиторию через GitHub/Codex. Обычно достаточно подключить в нём GitHub владельца репозитория. Сам репозиторий не становится публичным от передачи ссылки; участники и права доступа автоматически не добавлялись.

Проверка пакета:

```sh
python3 tools/verify_handoff.py
```
